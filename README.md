# Bold Restaurant Ghana

Static website for Bold Restaurant Ghana (12 Obenesu Cres, Accra). No build step.

- `index.html`: home page (hero slideshow, favourites, gallery, FAQ, find us)
- `menu.html`: standalone menu page
- `style.css`: shared styles for all pages
- `images/`: restaurant photos
- `icons/`, `favicon.*`, `site.webmanifest`, `og-image.jpg`: brand and link-preview assets
- `sitemap.xml`, `robots.txt`, `llms.txt`: search and AI-search discovery files
- `vercel.json`: caching and security headers

Live: https://bold-restaurant-ghana.vercel.app

Designed by [Baiden Creatives](https://baiden-creatives.vercel.app).
